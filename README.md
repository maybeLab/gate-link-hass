# GateLink HASS

[简体中文](README.md) | [English](README.en.md)

面向中国云门禁服务的 Home Assistant 自定义集成。通过手机号和短信验证码登录，跨小区选择门禁，为每扇绑定的门生成独立设备和 **开门** 按钮。

项目仓库：[maybeLab/gate-link-hass](https://github.com/maybeLab/gate-link-hass)。集成的内部标识（domain）为 `gate_link_hass`，安装目录为 `custom_components/gate_link_hass`。

## 非官方项目声明

GateLink HASS 是由社区独立开发的非官方项目，与门禁服务提供方不存在隶属或合作关系，也未获得其官方认可或背书。

## 功能

- 支持多个账号，每个账号可绑定多个小区的门禁。
- 查询全部授权门禁，支持楼栋门、自定义门和小区门。
- 门禁按钮可添加到仪表盘，用于自动化，或通过 HomeKit Bridge 桥接。
- 登录失效时暂停开门并提示重新登录，重新认证后保留原有绑定。
- 每个账号提供登录状态诊断实体，登录检查结果可在 Home Assistant **活动**中按列表查看。
- 在配置页面调整绑定；取消绑定会清理对应设备和实体。

## 使用要求

- Home Assistant Core **2026.10.0 或更高版本**。
- 已有可通过手机号和短信验证码登录的门禁账号，并具有目标门禁的权限。
- Home Assistant 能访问门禁云服务；开门需要网络连接。

## 使用范围与安全说明

- **授权范围**：仅可使用本人或已获授权的账号，操作自己具有访问权限的门禁。不得用于未授权访问或绕过访问控制；使用时应遵守适用法律和相关服务条款。
- **云服务依赖**：本项目依赖第三方云服务。接口、认证规则或服务可用性的变化可能导致短信、登录、门禁查询或开门功能不可用；项目无法保证持续兼容或服务可用性。
- **远程开门安全**：远程开门或设置开门自动化前，请确认目标门禁及现场环境安全，避免误触发。云服务的成功响应不代表门已实际打开，本集成不提供现场开关状态反馈。

## 安装

### HACS

目前通过 HACS 自定义仓库安装，尚未收录到默认仓库列表。可使用 [在 HACS 中打开此仓库](https://my.home-assistant.io/redirect/hacs_repository/?owner=maybeLab&repository=gate-link-hass&category=integration)，或按以下步骤添加：

1. 在 HACS 中打开 **自定义仓库**。
2. 填入 `https://github.com/maybeLab/gate-link-hass`，类型选择 **Integration**。
3. 搜索并下载 **GateLink HASS**。
4. 重启 Home Assistant。

### 手动安装

1. 从 [GitHub 仓库](https://github.com/maybeLab/gate-link-hass) 下载源码，将 `custom_components/gate_link_hass` 目录复制到 Home Assistant 的 `/config/custom_components/gate_link_hass`。
2. 重启 Home Assistant。

## 配置

1. 打开 **设置 → 设备与服务 → 添加集成**，搜索 **GateLink HASS**。
2. 输入手机号，提交以发送短信验证码。
3. 输入六位验证码；需要时可勾选重新发送。
4. 在“小区 / 门禁名称”列表中选择需要绑定的门禁，至少选择一扇门。
5. 设置请求超时并保存。

验证码仅用于当前登录过程，不写入账号配置。同一账号只添加一次；添加其他账号时重复上述步骤。

在集成的配置页面中可以修改绑定和请求超时。暂时消失或失去权限的已绑定门禁仍保留在配置中，可取消绑定；实际开门权限由服务端判断。不再使用账号时，可删除整个配置条目。

每个账号的配置页顶部展示脱敏手机号、用户 ID、本次登录检查结果、本次登录时间、最近成功检查时间，以及已绑定的小区和门禁数量。时间按 Home Assistant 配置时区显示；临时检查失败时显示“本次未确认”，保留最近成功检查的时间。

## 使用

每扇门对应一个设备和一个 **开门** 按钮。按钮默认使用门禁名称，不带小区名称；可在 Home Assistant 中自行重命名。可将按钮添加到仪表盘，也可在脚本或自动化的动作中调用：

~~~yaml
action: button.press
target:
  entity_id: button.gate_link_hass_entry
~~~

将示例实体 ID 替换为设备页面中的实际按钮实体 ID。按钮发送开门指令，不显示门的实际开关状态。

每次点击使用已保存的会话和绑定门禁信息，只调用一次开门接口。登录与权限状态通过开门接口响应判断。

同一门禁请求未完成时，再次点击会提示正在处理。开门请求不会自动重试；超时后结果可能未知，请先确认现场状态再决定是否重试。

### HomeKit

在 HomeKit Bridge 的实体选择中勾选需要桥接的开门按钮。按钮在“家庭”中表现为自动复位的开关。

## 登录与权限

登录状态以云服务响应为准。每个账号每天北京时间 **06:00** 自动检查登录，不受 Home Assistant 配置时区影响。服务端返回的检查参考时间更早时会提前检查，到时间不会直接判定账号失效。账号加载和打开配置页面时也会检查登录、查询门禁；点击开门按钮时直接调用开门接口。

服务端明确报告登录失效后，会暂停开门，通过 Home Assistant 通知提示重新认证。重新登录需使用原账号，完成后恢复原有绑定和设备、实体标识。

网络故障、超时和响应异常不会被当作账号失效；后台登录检查失败时，5 分钟后重试。门禁授权到期或权限不足需在门禁服务中处理。

### 登录状态与活动记录

在 **设置 → 设备与服务 → GateLink HASS → 设备** 中，选择 `GateLink HASS 账号 ****1234`（号码后四位对应账号），可查看 **登录状态**诊断实体。账号设备独立于各扇门的设备；多个账号分别展示。

| 登录状态 | 含义 |
| --- | --- |
| 登录有效 | 最近一次登录检查通过 |
| 登录失效 | 服务端已确认失效，需要重新登录；开门按钮暂停使用 |
| 本次检查失败 | 网络、超时或响应异常，本次未能确认；保留会话和最近成功检查时间，仍可尝试开门 |
| 尚未检查 | 尚无可用的检查结果 |

实体属性包含最近检查时间、最近成功时间、检查来源和安全的错误原因。即使启动时账号已失效，账号设备和诊断实体仍可查看，重新认证后恢复开门按钮。

打开侧边栏的 **活动**，按上述账号设备或其 **登录状态**实体筛选，即可查看启动、每日检查、失败重试、配置页面和重新认证的检查记录。每次实际检查都记录一条，即使连续多次成功也会保留；开门响应确认登录失效时也会记录一次，无需额外调用登录接口。

也可添加活动卡片：

~~~yaml
type: logbook
title: 账号登录检查
entities:
  - sensor.gate_link_hass_account_1234_login_status
hours_to_show: 168
~~~

将示例实体 ID 替换为账号设备页面里的实际实体 ID。历史由 Home Assistant 的 Recorder 保存，保留时长和筛选遵循其配置；需要启用 Recorder 和活动功能，并确保未排除此实体或检查事件。活动内容仅显示号码后四位和检查结果，不包含验证码或会话凭据。

账号凭据随集成配置保存在 Home Assistant 中，请妥善保护配置文件和备份。

## 常见问题

**没有看到可用门禁**

确认账号已获得小区和门禁权限。查询失败时可重试；已有绑定暂时不可用时，可以在配置页面刷新列表或取消绑定。

**提示重新登录**

在 **设置 → 设备与服务 → GateLink HASS** 中完成重新认证。已确认失效的会话不会在重启后恢复使用。

**从旧名称版本重新安装**

先删除旧集成的账号条目和安装目录，再安装当前版本，重新通过短信登录并选择门禁。内部标识已更换，原配置不会自动迁移。仪表盘、自动化和 HomeKit Bridge 中请重新选择新按钮实体。
